## 更新边界

- 当前 preview 包的清单签名和 SHA-256 校验有效，但平台包使用明确的 `unsigned-preview-v1` 诊断标记。
- Windows Authenticode、macOS Developer ID 签名和公证尚未完成，不能把 preview 包宣传为正式稳定商业版。
- 更新不会删除 SQLite、附件仓、工作区数据或局域网配对配置；安装失败的恢复契约已由自动化测试覆盖，但跨重启实机回滚仍需 Windows/macOS 验收。
- 网页在线版通过刷新获取新版本；单文件离线 HTML 需要重新下载新文件，浏览器关闭后不会自动替换本地文件。
- 支付、自动邮件发码、正式 KMS/HSM、正式商业 CDN、退款/换机售后和真实设备验收仍是正式商业发布前置条件。
- 公众号当前只保存自动回复和文章草稿，不直接群发；后台已核对主推文草稿和“工作台/前瞻版”关键词规则处于保存状态。文章和自动回复的本地源稿分别为 `docs/wechat-launch-article-v4.9.1.md` 与 `docs/wechat-auto-reply-v4.9.1.md`。
