## 可重复生成

前瞻版交付包由源码和受控构建产物组装，不把兑换码、许可证私钥或模型 Key 写入包内。重新构建前先生成唯一离线网页版、PDF、Windows 安装包和 macOS Universal DMG/ZIP，再执行：

```powershell
pnpm build:forward-package -- output/学工智伴-v4.9.2-前瞻版交付包-YYYYMMDD-r16-final
```

脚本会检查网页、Windows/macOS 安装包、三份 PDF 和脱敏样表是否齐全，扫描常见凭据格式，并在包根目录生成 `文件校验-SHA256.txt`。兑换码仍只通过维护者私下渠道发放。

服务器发布前可先运行 `pnpm prepare:preview-deployment`，它从 `output/desktop` 的实际文件生成 ASCII 文件名的 `latest*.yml` 和未签名 `manifest-v4.9.2-preview-unsigned.json`，避免中文交付文件名与更新清单不一致。服务器端使用 `scripts/publish-preview-v4.9.2.sh` 完成备份、签名、原子替换、API 发布和哈希回验；该脚本不包含任何密钥。

## 前瞻版体验顺序

1. 第一次打开 `学工智伴-v4.9.2-前瞻版离线网页版.html`，依次查看今日概览、学生台账、导入预览、谈心谈话、工作留痕、成绩、住宿、备份恢复和 AI 工作台；同一个入口同时承担样例体验和商业激活。
2. 只用虚构或脱敏数据，不导入真实姓名、学号、电话、心理材料、密码、模型 API Key 或敏感附件。
3. 需要体验商业授权时，在“商业授权”或灰色 AI 按钮中输入维护者私下提供的兑换码；前瞻版网页和桌面安装包都已连接 `https://license.windsky.store`，不需要再换另一个网页文件。
4. 正式签名许可证支持本地签名校验激活；四档商品码和友情 AI 码是服务端兑换凭据，必须联网核验，不能在完全断网时使用。桌面安装包会通过主进程联网，单文件 HTML 也需要保持网络可用。四枚商品码严格分别兑换 10 元普通版、20 元普通永久更新版、40 元 AI 增强版、60 元永久 AI 增强版；AI 档输入后可覆盖此前的基础档。20 元/60 元才有更新权益。桌面端与网页端的授权状态独立保存，同一通用商品码需在各端分别输入；数据同步不携带授权。AI 许可证激活后仍可输入维护者私下提供的友情 AI 码，工作台会自动配置开发者托管 AI；重启后托管资格应保持。没有友情码时仍需体验者自行配置模型服务和模型 Key。
5. 反馈只提供页面名称、复现步骤、错误码、预期结果和脱敏截图。有效建议经核验采纳后，按前瞻体验计划规则赠送永久 AI 增强版。

## 当前限制

- Windows 测试安装包未使用正式代码签名证书，Windows 可能显示安全提示；这不代表安装包被篡改。
- 当前服务器仍是授权服务前瞻环境，签名器为部署侧 staging signer，不是正式 KMS/HSM。
- 支付、自动邮件交付、正式更新 CDN、Windows Authenticode、macOS Developer ID 签名和公证仍不能以前瞻版交付包作为已完成证据；当前 `license.windsky.store` 只证明 preview 下载和更新入口可访问。
- 单文件 HTML 关闭后不能在后台自动更新文件；正式业务数据仍应使用工作台的备份和恢复功能。
- 如果激活窗口仍显示 `LICENSE_SERVICE_UNAVAILABLE`，先确认使用的是本轮新包、设备可以打开 `https://license.windsky.store/api/v1/health`，再重试；不要把兑换码当作正式许可证离线使用。
- r16 交付包中的 `更新元数据/` 是按包内实际安装程序生成的完整性核对资料，不是服务器端更新清单。由于产品版本号仍为 `4.9.2`，不能直接拿它替换远端 preview 清单；下一次软件内更新必须提升版本号、重新签名并部署。
