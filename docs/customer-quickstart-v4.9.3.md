# 学工智伴 v4.9.3：普通用户购买、激活、更新与互通

这份说明只解决四个问题：在哪里买、买完拿什么、怎么激活、以后怎么更新和换设备。未激活时只能浏览、筛选和查看样例数据；不能新增、编辑、删除、导入、恢复、同步真实资料，也不能改写样例或上传本地文件。激活基础版或更高档位后可录入真实资料；表格、模板、政策 PDF、照片和长期文件归档只在桌面端开放。

## 一、你只需要记住这条流程

```text
选择档位 → 完成支付 → 获得许可证 → 下载桌面端或唯一离线网页版 → 激活 → 配对手机/网页端 → 日常备份和更新
```

许可证不是学生数据，也不是 AI 模型 Key。许可证只决定产品档位和更新权益；模型 Key 由你自己配置，模型调用费用不包含在产品价格内。桌面端和网页端各自保存激活状态，同一商品码要在需要使用的每一端分别输入；局域网同步不会自动带走授权。

## 现在你需要做什么

当前版本是 v4.9.3 前瞻交付版，不把未签名、未公证包冒充正式商业稳定版。最新包和手册可以从维护者提供的 `v4.9.3` 下载目录获取；preview 更新清单只允许已激活且拥有永久更新权益的设备读取。10 元和 40 元档不能从软件内获取版本更新。前瞻包仍使用诊断签名标记，正式商业包要以平台代码签名和公证状态为准。

1. 打开工作台，先使用样例数据体验功能；未激活时不要导入真实学生资料；
2. 打开“购买、激活与服务说明”，选择想购买的档位；
3. 当前购买页为 `https://license.windsky.store/customer`；支付入口尚未接通时不要重复创建订单，也不要导入真实数据；需要人工核验请联系微信 `Windsky0823`。

工作台会记住你选中的档位，并把它带到订单页。用户不会再次从头寻找产品，也不会因为创建订单就被误提示“已经付款”。

## 三、在哪里买、钱到哪里

正式上线后，工作台里的“购买所选档位”按钮只打开受控购买页，并自动带入用户刚才选中的产品。购买页会明确显示商品、金额、支付状态和取件方式。支付平台负责收款和订单状态，独立授权服务负责签发许可证，下载站只负责安装包分发，三者职责分开。

当前受控购买页已经部署，四档产品目录和订单页面可访问；真实微信支付、商户配置、邮件、KMS 和支付 webhook 仍未接通，因此当前页面只能创建待处理订单，不能把它当成已经可以自动收款的正式商城。页面不会伪造“支付成功”。

如果微信支付商户还没有审核完成，试运营可以把链动小铺作为临时收款页。它只承担付款和临时交付，不改变工作台内的档位、激活和授权规则；稳定的正式方案仍是自有购买页接微信支付。没有官方签名回调时，不能让客户端自己判断已付款。

不要把激活码放进公开百度网盘、微信群公告、源码仓库或普通备份。短期人工发码也必须通过受控订单取件页或一对一交付，并保留订单号和发放记录。

## 四、付款后怎么拿到激活码

正式服务有两种交付方式，用户只会看到其中一种：

1. **订单页取件**：付款被支付平台 webhook 或维护者后台确认后，订单状态变为“已完成”，点击“下载许可证文件”。
2. **邮件取件**：付款确认后，系统向下单邮箱发送许可证文件或受保护的取件链接。

收到的 `.cwb-license` 文件或 `CWB-LIC-1.…` 激活码只在本机输入。不要发到群里，也不要上传到网盘。许可证独立签名，最多绑定一个工作区的 3 台设备；换机可以先在设备管理中解绑旧设备。

## 已购买后如何升级 AI

如果已经购买普通版或普通永久更新版，打开同一个“购买、激活与服务说明”，选择更高的 AI 档位，按钮会变成升级流程。工作台把当前许可证交给授权服务验证，服务端按原档位抵扣后计算差价：普通版升级 AI 增强版为 30 元，普通永久更新版升级 AI 增强版为 20 元；永久 AI 档位分别按 50 元和 40 元计算。前瞻体验优惠和赠送资格以人工核验结果为准。

支付完成后，授权服务会生成新的独立许可证并发送到订单邮箱。回到工作台导入新许可证即可解锁 AI；学生数据、工作区和三端配对关系不因升级而删除。客户端不能自己修改差价，也不会把升级当成一次全价新购。

## 五、第一次激活

1. 从交付包中选择 Windows x64/arm64 安装程序，或 macOS Universal ZIP/DMG。Windows 安装完成后会创建“学工智伴”桌面快捷方式；若安装器被系统策略拦截，首次打开应用会自动补建。macOS 请先将应用拖到“应用程序”文件夹再打开，首次启动会在桌面创建“学工智伴”别名；直接从 DMG 运行不会创建别名。当前前瞻包未签名、未公证，系统出现安全提示属于预期；正式商业包必须以签名和公证状态为准。
2. 打开工作台，先选择或创建工作区。
3. 点击右上角盾牌图标“购买或激活许可证”；也可以打开“设置 → 授权、购买与版权 → 输入激活码”。点击任一灰色锁定功能同样会直接进入“商业授权”。
4. 在“商业授权”中粘贴激活码，点击“激活许可证”；也可导入 `.cwb-license` 文件或识别许可证二维码。窗口先显示“授权服务已就绪”，提交后会显示“正在核验”，成功后会弹出“激活完成”，并立即列出当前端已解锁的“真实数据、文件上传、AI、软件更新、友情 AI”权益。
5. 四类商品码分别对应 10 / 20 / 40 / 60 元档位。输入 AI 档位码会直接覆盖基础功能边界并解锁真实数据和 AI，不需要删除已有数据；只有 20 元和 60 元档带软件内更新权益。前瞻贡献用户如收到友情 AI 码，必须先完成 40 元或 60 元 AI 档激活，再在同一窗口的“友情 AI 服务”处输入；它只开通托管 AI，不改变档位或更新权益。
6. 正式签名许可证可以在本地完成签名校验激活；前瞻商品码和友情 AI 码仍需要联网核验。桌面端会由主进程发送 HTTPS 请求，单文件 HTML 也可以在联网状态下兑换。个人文件上传只在桌面端显示。桌面端与离线网页版需要分别激活，数据同步不会传递激活状态。
7. 如果买的是 AI 档位，再到 AI 工作台配置自己的模型接口和 API Key；也可以打开“AI 对话”直接提问。独立对话默认不发送学生数据，只有主动选择范围、勾选并预览后才发送脱敏上下文。已经兑换友情 AI 服务的前瞻体验用户无需填写 API Key、模型名称或服务地址。

没有 AI 授权时，AI 按钮仍然可见但会锁定，不会发送请求，也不会保存 AI 结果。只有许可证不等于已经配置模型，两者是两件事。

## 六、桌面端、唯一离线网页版和手机端怎么互通

推荐把安装了桌面端的办公电脑设为局域网数据中枢：

1. 在桌面端打开“平台联动”，点击“启动局域网数据中枢”。
2. 点击“生成一次性配对码”，桌面端会显示地址、过期时间和证书指纹。
3. 手机或另一台电脑连接同一 Wi-Fi，打开网页端，输入地址或扫描配对二维码。
4. 回到桌面端确认设备名称和配对请求，核对证书指纹后点击“确认配对”。
5. 配对成功后，手机和网页端通过同步接口读取和提交临时录入数据；个人附件不从网页端建立或长期保存，附件归档、哈希校验和换机恢复在桌面端完成。

数据关系很简单：办公室桌面端/局域网主机保存 SQLite、附件和审计；下班后的网页端和手机端是受控客户端，不直接打开 SQLite 文件。首次配对后，客户端把暂时无法发送的操作放进本地离线队列；第二天桌面主机运行、两端在同一局域网且页面打开或回到前台后，会自动 push/pull，主机恢复后再提交。

不同字段的修改可以自动合并；同一个字段同时被两台设备修改时，进入“冲突收件箱”，由老师选择主机值、客户端值或手工编辑。系统不会用“最后保存的人赢”静默覆盖。

授权和数据是两件事：桌面端与唯一离线网页版都提供同一个四档激活入口，但激活状态独立保存。需要在网页端使用真实数据时，也要在网页端输入同一档位商品码；同一通用商品码会为各端独立完成授权，不会因为桌面端已激活而自动传播。数据是否互通取决于是否完成桌面主机配对，而不是只看激活状态。网页端的设备令牌只保留在当前页面会话，关闭后需要重新连接或配对。

## 七、以后怎么更新，不用卸载

### 桌面端

桌面端打开“版本更新”，点击“检查更新”。系统依次完成：

```text
检查更新权益 → 下载临时包 → 校验清单签名和 SHA-256 → 创建恢复点 → 确认安装并重启
```

更新不会删除学生资料、SQLite、照片、证书、活动附件、工作区目录或局域网配对数据。当前 preview 更新服务已经部署，v4.9.0 及以上的正确配置桌面包可获取清单；更新失败会保留旧版本和恢复点，不要先卸载，也不要手动删除数据目录。

普通版和 AI 增强版不能从软件内获取版本更新清单；只有普通永久更新版和永久 AI 增强版可以检查、下载和安装软件更新。安全漏洞和严重数据修复仍会按维护策略提供必要处理，不以更新权益过期为理由阻断安全提示。

### 唯一离线网页版

交付包只提供一个离线网页版 HTML 文件；电脑浏览器和手机浏览器使用同一个文件，不再区分“体验版”和“授权体验版”。它适合查询、临时录入和回办公室后同步，不作为长期附件仓或主备份位置。新版本需要重新下载这个文件并打开；浏览器关闭后不能在后台替换本地文件。这是浏览器运行方式的限制。重要资料请回到桌面端归档和备份。

## 八、换电脑和恢复数据

1. 在旧电脑“平台联动/备份迁移”里执行一次完整备份。
2. 导出恢复包时把 SQLite、附件索引、附件原始内容和校验信息一起导出。个人文件会随桌面工作区的加密附件仓一并带走，不需要逐个重新找原文件。
3. 新电脑安装新版本，先创建空工作区并打开“恢复”。
4. 先看差异预览和容量检查，再确认恢复。
5. 恢复完成后核对学生数量、业务记录数量、附件数量和哈希。
6. 最后重新输入许可证并在设备管理中确认设备数量。

许可证丢失不会导致学生数据丢失；但许可证不能从业务备份中恢复，需要通过正式订单或售后流程重新激活。恢复口令请离线保管，维护者不会提供绕过签名的后门解锁。

## 九、遇到问题先看哪里

| 现象 | 先做什么 |
| --- | --- |
| 购买后没有许可证 | 在订单页刷新状态；确认支付是否真的被平台确认，不要重复付款 |
| AI 仍然灰色 | 检查许可证档位，再检查模型 Key；普通版不会解锁 AI |
| 手机连不上电脑 | 确认同一 Wi-Fi、主机仍在运行、配对码未过期，并重新核对证书指纹 |
| 更新按钮不可用 | 检查更新权益和网络；浏览器/离线版需要手动获取新文件 |
| 数据看起来少了 | 先停止继续编辑，查看数据源、离线队列、冲突收件箱和最近恢复点 |
| 激活码泄露 | 立即联系维护者撤销并重新签发，不要继续在群里转发 |

如果激活后没有出现“激活完成”，先从 [`v4.9.3 下载中心`](https://license.windsky.store/downloads/v4.9.3/) 重新下载安装程序，确认使用的是当前授权网络修复包，而不是旧的同版本修订包。确认设备能够打开 `https://license.windsky.store/api/v1/health`，再回到“商业授权”重新提交。前瞻兑换码不是离线许可证；只有正式签名许可证可以在本地完成签名校验。若窗口显示具体错误，请把版本号、页面名称、错误码和脱敏截图发给开发者，不要发送激活码本身。

反馈问题时只提供脱敏描述、复现步骤、版本和错误码，不发送真实姓名、学号、电话、心理材料或业务附件。
